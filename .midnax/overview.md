# FernandoPazCavalcante's Org — overview

## LazySwap — Organization Identity

**What they build**

LazySwap is a self-custody terminal wallet and CLI for executing cross-chain swaps directly on-chain across EVM networks (Ethereum, BSC, Polygon, Arbitrum, Base) and Bitcoin via THORchain routing. The platform combines a Go-based TUI wallet with Solidity smart contracts (FeeVault, ERC-721 LazySwapPass) and a React landing page, enabling users to manage private keys locally and perform token swaps without intermediaries.

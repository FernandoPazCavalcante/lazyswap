# FernandoPazCavalcante's Org — overview

## Organization Identity Overview

**What they build**

LazySwap is a self-custody terminal wallet (TUI/CLI) for decentralized exchange swaps and cross-chain Bitcoin transactions, built in Go with Bubble Tea. The organization also maintains supporting infrastructure: Solidity smart contracts for referral fee management, a React-based marketing site with Cloudflare Workers backend, and curated AI agent skills for marketing automation. Secondary projects include Helm charts for self-hosted Flagsmith deployments and Docker Compose stacks for home server infrastructure.

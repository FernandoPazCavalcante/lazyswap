# FernandoPazCavalcante's Org — overview

## LazySwap — Org Identity

**What they build**

LazySwap is a self-custody terminal wallet and DEX aggregator for on-chain swaps across EVM chains and Bitcoin via THORchain. The core product is a Go-based CLI/TUI that executes token swaps directly from user wallets without intermediaries, paired with Solidity smart contracts (fee vault, NFT pass) and a React marketing site deployed to Cloudflare Workers. Users retain full custody; swaps are quoted and executed against Uniswap V2, PancakeSwap, and cross-chain liquidity pools.

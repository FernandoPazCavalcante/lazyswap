# FernandoPazCavalcante's Org — overview

## LazySwap — Organization Identity

**What they build**

LazySwap is a cross-chain swap terminal and smart contract platform. The core product is a Go-based CLI/TUI wallet enabling on-chain token swaps across EVM networks (Ethereum, BSC, Sepolia) and Bitcoin via aggregated liquidity providers (LI.FI, NEAR Intents, THORchain). The platform includes Solidity smart contracts (fee vault, ERC-721 pass system) and a React marketing site deployed serverless on Cloudflare Workers.
